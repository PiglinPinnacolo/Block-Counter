# Block-Counter
あらゆるブロックの破壊、設置をカウントするMOD。タイムを計る機能付き。
ブロックの種類問わず、GUIを画面上にピン止めできます。
ピン止めした後に破壊表示、設置表示をボタンで切り替え可能。
ピン止めされた項目を消す場合は、選択後DELETEキーで削除可能。
GUI位置微調整用のボタンを用意。
ctrl+Cでconfigを開きます。
configで文字の大きさ変更可能
作業時間を計るためにストップウォッチ機能を付けています。これはインベントリにボタンを設置しています。
ストップウォッチは直近3つまでLAPを記録し、古いものは上書きで消えていきます。
カウントリセットはキーバインドもしくは、/blockcounter resetで可能
ワールドごとに設定を保持しピン止めやカウントの情報はログアウト後も保持します。
